# 🛡️ PS-SecMon - Monitor de Segurança e Integridade

Monitor de integridade de arquivos e detecção de tentativas de login em tempo real utilizando PowerShell. Este projeto atua como um **HIDS (Host-based Intrusion Detection System)** simplificado.

Aqui está o sistema em funcionamento:

## ✨ Funcionalidades
- **Monitoramento FIM (File Integrity Monitoring):** Detecta criação, edição e exclusão de arquivos em tempo real.
- **Detecção de Brute Force:** Monitora falhas de login (Event ID 4625) no Windows.
- **Logs de Auditoria:** Gera registros automáticos em arquivo `.log`.

## 🛠️ Como usar
1. Execute o PowerShell como Administrador.
2. Rode o script `monitor.ps1`.
3. Verifique os alertas coloridos no terminal e os logs na pasta.
